# DESIGN.md

## 气质与意象
清晨的数据实验室——白色台面上铺着笔记本，屏幕上是刚跑完的数据图表，咖啡还在冒着热气。简洁、通透、有条理。信息像一张精心排版的研究报告，不是炫技的舞台，是安静展示实力的橱窗。

## 差异化核心
- 浅色底（不是深色太空风），让内容呼吸
- 编辑式排版（文字层级驱动，不是卡片堆砌）
- 数据可视化作为装饰语言（小图表、sparkline、环形指标）
- 留白大胆，内容分区清晰
- 交互克制，只留关键微动效
- 无粒子、无毛玻璃、无进度条——用数字和图表说话

## 字体排版
- 标题：'Inter', sans-serif，600/700 weight，字间距 -0.02em
- 正文：'Inter', 'PingFang SC', sans-serif，400 weight
- 数据/代码：'JetBrains Mono', monospace
- 大标题字号 48-64px，正文 16px，辅助 14px

## 动效
- 滚动渐显（opacity + translateY，极缓）
- 环形指标从 0 到目标值的动画
- 悬停卡片微微上浮 + 阴影加深
- 导航锚点平滑滚动

## 页面结构
1. 顶栏（品牌名 + 锚点导航，纯文字，无背景模糊）
2. Hero（左大标题 + 右侧小仪表盘装饰）
3. 关于（双栏：左文字叙述 + 右关键指标环形图）
4. 技能（标签云 + 分组柱状小图，不是进度条）
5. 项目（Bento 网格，大小不等）
6. 时间轴（竖向单线，节点 + 简洁文字）
7. 联系（单行信息条 + CTA）
8. 页脚

## 设计禁忌
- 不用深色背景
- 不用粒子动画
- 不用毛玻璃效果
- 不用水平进度条
- 不用居中大标题 Hero
- 不用紫色渐变
